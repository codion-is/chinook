* Custom column type

** <<_album, Album Tags>>

* Database functions

** <<_updatetotalsfunction, UpdateTotalsFunction>>

*** Used in <<_invoicelineeditmodel, InvoiceLineEditModel>>

** See TrackCellEditorFactory in <<_tracktablepanel, TrackTablePanel>>

* Custom input fields

** <<_coverartpanelbuilder, CoverArtPanelBuilder>>

** <<_albumtagspanelbuilder, AlbumTagsPanelBuilder>>

*** Used in <<_albumeditpanel, AlbumEditPanel>>

** <<_durationpanelbuilder, DurationPanelBuilder>>

*** Used in <<_trackeditpanel, TrackEditPanel>> and <<_tracktablepanel, TrackTablePanel>>

* Custom condition panel

** <<_invoiceconditionpanel, InvoiceConditionPanel>>

*** Used in <<_invoiceeditpanel, InvoiceEditPanel>>

* Customizing the table popup menu

** See <<_tracktablepanel, TrackTablePanel>> and <<_playlisttablepanel, PlaylistTablePanel>>

* Custom condition model operators

** See TrackConditionModelFactory in <<_tracktablemodel, TrackTableModel>>

* Custom detail panel layout

** See <<_invoicepanel, InvoicePanel>> and <<_playlistpanel, PlaylistPanel>>

* Edit panel in dialog

** See <<_playlistpanel, PlaylistPanel>> and <<_playlisttracktablepanel, PlaylistTrackTablePanel>>

* Language selection

** See <<_chinookapppanel, ChinookAppPanel>>

* Custom shortcut key

** See <<_chinookapppanel, ChinookAppPanel>>

* Overridden resources

** <<_chinookresources, ChinookResources>>

* Text field selector

** See <<_customereditpanel, CustomerEditPanel>>

* Search field selector

** See <<_invoiceeditpanel, InvoiceEditPanel>>

** <<_trackselectorfactory, TrackSelectorFactory>> Used in

*** <<_invoicelineeditpanel, InvoiceLineEditPanel>>

*** <<_playlisttrackeditpanel, PlaylistTrackEditPanel>>

*** <<_playlisttracktablepanel, PlaylistTrackTablePanel>>

*** <<_trackeditcomponent, TrackEditComponent>>

* Common Table Expression

** See <<_analyticsmodel, Analytics>>

* Custom components

** See <<_preferences_ui, Preferences UI>>

* Automatic EditPanel updates

** See <<_preferenceseditpanel, PreferencesEditPanel>>

* Lookup table cleanup

*** <<_artisttablepanel, ArtistTablePanel>>

* Detail editor

*** <<_customereditmodel, CustomerEditModel>>

*** <<_customereditpanel, CustomerEditPanel>>

* Multiple detail editors

*** <<_artisteditmodel, AristEditModel>>

*** <<_artisteditpanel, ArtistEditPanel>>

* Persistance layer used in a web service

** <<_service, ChinookService>>

* Table joins

* Custom condition

** <<_track_domain_implementation, Track>>

* Non-embedded edit panel

* Custom edit control

** <<_employeetablepanel, EmployeeTablePanel>>

* Database migrations

** <<_database_migration, MigrationManager>> - Hybrid JDBC/Entity approach for schema versioning

* Serialization filter logging

** <<_chinook_server, Chinook Server>> - Configuring java.util.logging from the classpath

* Distribution and packaging

** <<_distribution, Distribution>> - JLink/JPackage configuration with modular dependencies

NOTE: For the Gradle build configuration see <<#_build, Build>> section.

[#_session_context]
== Session context

Authenticating against the application instead of the database, as <<#_chinookauthenticator,ChinookAuthenticator>>
does, leaves the database with a single shared user doing everyone's work. Whatever the database would like to
do with the real identity - an audit trigger recording who changed a price, a view showing a sales
representative only their own customers - no longer has anything to go on.

A `SessionContext` puts the identity back on the connection, where SQL can read it. The server applies it
each time a connection is handed to a client and removes it again on the way back, which with a connection
pool means on every check out, so it is worth keeping cheap.

Note that this is only needed for what the database can not be told more directly: the client's user,
application and host are set as JDBC client info by the server on its own, where the database supports it.
H2 supports none of it, hence the session variable below.

[#_distribution]
== Distribution

This section covers the distribution setup for the Chinook application, which creates several distribution variants from a single codebase, custom runtime images via jlink and native installers via jpackage, using the https://github.com/beryx/badass-jlink-plugin[Badass JLink Plugin].

=== Overview

The Chinook project creates several distribution variants:

* **Client distributions**: Local, Remote (RMI), and HTTP connections
* **Server distributions**: Application server and monitoring tools
* **Load test distributions**: Performance testing tools for different connection types
* **Service distribution**: REST API server

Each distribution is configured to include only the necessary dependencies and modules, resulting in optimized runtime images.

=== Key Plugins

==== Badass JLink Plugin

The https://github.com/beryx/badass-jlink-plugin[Badass JLink Plugin] (`org.beryx.jlink`) is the cornerstone of the distribution setup. jlink only links explicit modules, so the plugin takes a pragmatic approach: **it combines the non-modular dependencies, automatic modules included, into a single merged module** with a generated module descriptor, which jlink then links along with the rest.

NOTE: Applying the Badass JLink Plugin automatically applies the Application plugin, providing access to `mainClass`, `applicationDefaultJvmArgs`, and other application configuration properties.

The tasks Chinook uses:

* `jlink` - Creates a custom runtime image containing only the required modules
* `jlinkZip` - Zips the runtime image
* `jpackage` - Creates a platform-specific installer (.msi, .deb, .dmg) from the runtime image

==== Extra Java Module Info Plugin

The https://github.com/gradlex-org/extra-java-module-info[Extra Java Module Info Plugin] (`org.gradlex.extra-java-module-info`) adds module information to libraries lacking it. Once applied, it refuses a dependency which is neither a module nor given module information, so each plain jar in the build, one with neither a `module-info.class` nor an `Automatic-Module-Name` in its manifest, needs an entry.

Chinook needs a single entry, for Adobe's `xmpcore`, a plain jar the JasperReports PDF exporter, `jasperreports-pdf`, depends on, using `automaticModule()`, which gives a plain jar a module name, making it an automatic module.

The entry lives in a convention plugin in `buildSrc`, applied by the client side modules, where the reports are exported to PDF:

Several modules exist solely to create different distribution configurations. They contain no code, only build configuration:

* `chinook-client-local` - Client with embedded database connection

* `chinook-client-http` - Client using HTTP for remote connections
* `chinook-load-test-remote` - Load testing tool using RMI
* `chinook-load-test-http` - Load testing tool using HTTP

Each configuration module:

. Depends on the base implementation module

=== JPackage Configuration

The jpackage integration creates platform-specific installers from the jlink runtime images.

==== Platform-Specific Installers

Each platform gets appropriate installer configuration:

[source,kotlin,options="nowrap"]
----
include::{root-dir}/chinook-server/build.gradle.kts[tags=jpackagePlatforms]
----

* **Linux**: Creates a .deb package with a desktop shortcut
* **Windows**: Creates an .msi installer with Start menu and desktop shortcuts, and console output for the server
* **macOS**: Creates a .dmg disk image

The configuration options used:

* `installerType` - Specifies installer format (msi, deb, dmg)
* `installerOptions` - Platform-specific installer options (--win-menu, --linux-shortcut, etc.)
* `imageOptions` - Runtime image options (--win-console for server applications)
* `icon` - Platform-specific application icons (.ico, .png, .icns)

NOTE: jpackage can only create installers for the platform it runs on.

==== Dynamic Naming Strategy

Chinook uses dynamic naming to include version and platform information:

* **Pattern**: `{project-name}-{version}-{platform}`
* **Benefits**: Easy identification, parallel builds, artifact organization
* **Implementation**: Automatic OS detection with `OperatingSystem.current()`
